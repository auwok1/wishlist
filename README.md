# WishList

Адаптивное PWA-приложение для общих списков желаний и бронирования подарков.

## Что уже реализовано в первой версии

- Анонимная авторизация Supabase без почты и пароля (имя + анонимная учётная запись на устройстве).
- Создание групп и приглашение по ссылке.
- Ограничение 25 участников на группу (проверяется транзакционно на сервере).
- Список участников и личные списки желаний.
- Добавление подарка с описанием, ссылкой и фотографией.
- Бронирование подарка через серверную функцию с защитой от двойного бронирования.
- Отмена собственного бронирования.
- Скрытие бронирования от владельца подарка, чтобы сохранить сюрприз.
- Удаление участника и группы владельцем.
- Русский/английский интерфейс, светлая/тёмная/системная тема.
- Адаптивная вёрстка для мобильных и десктопных экранов.
- PWA manifest для установки на главный экран.

## 1. Требования

- Node.js 20 или новее
- Аккаунт Supabase

## 2. Настройка Supabase

1. Создайте проект на https://supabase.com.
2. В Dashboard откройте **Authentication → Sign In / Providers** и включите **Anonymous Sign-Ins**.
3. Откройте **SQL Editor → New query**, вставьте всё содержимое `supabase/schema.sql` и нажмите Run.
4. В **Project Settings → API** скопируйте Project URL и anon/public key.
5. Создайте файл `.env.local` в корне проекта по образцу:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

Не помещайте `service_role` key в браузерный проект.

## 3. Запуск локально

```bash
npm install
npm run dev
```

Vite покажет локальный адрес, обычно `http://localhost:5173`.

## 4. Сборка

```bash
npm run build
npm run preview
```

Папку `dist` можно разместить на Vercel, Netlify или другом статическом хостинге. Для PWA и работы на телефонах через интернет нужен HTTPS.

## Важное ограничение режима без регистрации

Анонимная учётная запись привязана к браузеру/устройству. Если пользователь очистит данные браузера, переустановит браузер или сменит телефон, доступ к старой анонимной учётной записи может быть потерян. В следующем этапе стоит добавить необязательное восстановление доступа по email или одноразовой ссылке, сохранив возможность входа без регистрации.

## Текущие границы MVP

- Список групп обновляется при повторном открытии; realtime-подписки на изменения ещё не подключены.
- Для изображений сейчас включён публичный bucket, а чтение ограничивается приложением и RLS на метаданные. Перед публичным запуском лучше перейти на приватный bucket и выдавать signed URLs.
- Удаление участника удаляет его желания в конкретной группе.
- PWA manifest добавлен; для полноценного install prompt и офлайн-кэша следующим этапом добавляются service worker и иконки приложения.
